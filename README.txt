FF Championship Tournament Manager - V16

Perubahan utama:
- Seleksi Regular Season dipisahkan menjadi dua konfigurasi:
  1. 2 grup per matchday: seleksi memakai klasemen Overall.
  2. 1 grup per matchday: seleksi memakai urutan klasemen grup bergilir A/B/C.
- Masing-masing mode memiliki pengaturan sendiri untuk:
  - Posisi langsung Grand Final
  - Posisi awal Play-In
  - Posisi akhir Play-In
- Mengganti mode matchday tidak mencampur konfigurasi seleksi kedua mode.
- Klasemen grup tetap digunakan sebagai sumber seleksi hanya pada mode 1 grup per matchday.
- Fitur kill pemain, tab Regular Season/Play-In/Grand Final, roster, Play-In, Grand Final, localStorage, dan fitur sebelumnya tetap dipertahankan.

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html di browser atau gunakan Live Server di VS Code.
